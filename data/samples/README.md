# Sample swings

`swing_sample.json` is one real backhand from this morning's session (IMG_2116 iPhone plus IMG_5342 iPad, two-camera triangulation, 120fps). It is a `Swing` from `lib/ghost/types.ts`: 33 joints per frame, metres, hip-centred, y up.

`contactFrame` is approximate: it is the frame where the right wrist moves fastest, not a measured ball contact.

Use it to build the 3D replay, physics and coach before the pipeline CLI is finished. Check any swing file with `python scripts/check_swing.py <file>`.
